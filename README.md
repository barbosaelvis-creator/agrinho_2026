# Agrinho 2026 – Agro Negócios e Adubação (Jogo Interativo)

## 🎮 Descrição do Projeto

Este projeto é um **jogo educativo sobre Agro Negócios e Adubação**, desenvolvido em **p5.js** para o **Agrinho 2026**. Ele combina diversão, aprendizado e interação, mostrando como a aplicação de adubo e fatores como a chuva podem aumentar a **produtividade agrícola** e o **lucro de uma fazenda sustentável**.

O jogo termina com um **quiz interativo** inspirado no Quizizz para reforçar o aprendizado.

---

## 🌱 Funcionalidades

- Plantação de **milho animada**, crescendo com o tempo.
- **Aplicação de adubo** pelo jogador para aumentar o crescimento das plantas.
- **Chuva animada**, que melhora a fertilidade do solo.
- **Trator animado** espalhando adubo pelo campo.
- Contagem regressiva de **60 segundos** para maximizar a produção.
- **Cálculo de produtividade** (sacas de milho) e lucro em tempo real.
- **Quiz final interativo** com perguntas sobre adubação, chuva e agro negócios.
- Feedback visual e educativo durante todo o jogo.

---

## 🕹️ Como Jogar

1. Abra o projeto no **p5.js Web Editor**.
2. Durante o jogo:
   - Pressione **A** para ativar/desativar o adubo.
   - Pressione **C** para ativar/desativar a chuva.
3. Observe o crescimento das plantas e tente maximizar a **produtividade e lucro**.
4. Após o tempo acabar, o **quiz final** aparecerá:
   - Clique nas opções corretas para responder.
   - Veja quantas respostas você acertou e a produtividade final.
